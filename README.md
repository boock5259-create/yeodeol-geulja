# 여덟 글자 · 우리 궁합

사주로 보는 두 사람의 궁합 웹앱. 무로그인·무저장, 링크 공유로 상대와 함께 결과를 여는 방식.

## 구성
- `index.html` — 자립형 단일 페이지 (사주 4기둥 계산, 오행 궁합, MBTI 결합, 9:16 공유 카드)

## 배포
Vercel 정적 호스팅. `main` 브랜치에 push하면 자동 배포.
