# 캐릭터 이미지 (그리스신화) — 여기에 20장 넣으세요

앱이 각 사람의 **일간(물상) + 성별**로 자동 매칭합니다. 파일명 규칙: `{물상}_{남|여}.png`
- 이미지 없으면 자동으로 골드 오행 심볼로 폴백(깨지지 않음).
- 세로형(3:4 정도) 권장. 배경 심플·투명이면 카드에 더 잘 어울림.

## 필요한 파일 20장 (한글 파일명 그대로)

| 물상(일간) | 남자 | 여자 | 참고 신 |
|---|---|---|---|
| 바다 (임수) | `바다_남.png` | `바다_여.png` | 포세이돈 / 암피트리테 |
| 태양 (병화) | `태양_남.png` | `태양_여.png` | 아폴론 / 태양 여신 |
| 큰나무 (갑목) | `큰나무_남.png` | `큰나무_여.png` | 아틀라스 / 여성 거신 |
| 화초 (을목) | `화초_남.png` | `화초_여.png` | 아도니스 / 아프로디테 |
| 촛불 (정화) | `촛불_남.png` | `촛불_여.png` | 남성 화로신 / 헤스티아 |
| 큰산 (무토) | `큰산_남.png` | `큰산_여.png` | 크로노스 / 가이아 |
| 텃밭흙 (기토) | `텃밭흙_남.png` | `텃밭흙_여.png` | 남성 수확신 / 데메테르 |
| 무쇠 (경금) | `무쇠_남.png` | `무쇠_여.png` | 헤파이스토스 / 여성 대장장이 |
| 보석 (신금) | `보석_남.png` | `보석_여.png` | 남성 지혜신 / 아테나 |
| 이슬비 (계수) | `이슬비_남.png` | `이슬비_여.png` | 남성 전령신 / 이리스 |

> 파일명은 위와 **정확히 동일**하게(공백 없음, `.png`). 넣고 나면 결과·솔로카드·공유카드·상대 미리보기에 전부 자동으로 뜹니다.
